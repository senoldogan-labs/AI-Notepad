Gistsmith 0.2.11 makes answers in Ask flow smoothly and lines up the Ask box on meeting pages.

## Improvements
- **Smoother answers in Ask.** Answers now appear without stutter while they are being written, even long ones, and the app stays responsive in the meantime. You can select text in an answer as soon as it is finished.
- **Ask box lined up with the note (Mac).** On a meeting page, the Ask box now sits centered under the note instead of drifting to one side in wide windows.

Requires macOS 15 or later on Apple silicon.
