Gistsmith 0.1.12 helps us find out where getting started goes wrong, so we can fix it.

## Improvements
- **Anonymous first-run counts.** When "Share anonymous usage statistics" is on in Settings, Gistsmith counts the first launch and each sign-in step: the sign-in window opened, was closed, failed, or finished. Each count carries only the step, the sign-in provider or failure type, and the app version. No account, name, email or device identifier is sent. Turn it off any time in Settings › General.

Requires macOS 15 or later on Apple silicon.
